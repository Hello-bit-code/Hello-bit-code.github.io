ANC 컨트롤

자동 ANC와 수동 ANC 중 원하는 모드를 선택하세요.

마이크의 저주파 소리를 실시간 반전해 출력합니다. 자동 모드와 수동 모드를 선택할 수 있습니다.

기능 한계 — 일반 블루투스 이어폰 및 브라우저에서는 귀 위치의 상쇄 효과를 보장할 수 없습니다. 오히려 소음이 커지거나 피드백이 발생할 수 있습니다. 이 페이지는 기기의 미디어 음량을 읽거나 바꾸지 못합니다. 이어폰을 귀에서 뺀 상태에서 시작하고, 기기 음량을 낮게 유지하세요.

작동 모드

수동 설정도 출력 상한이 제한됩니다. 이 값은 실제 소음 감소율이 아닙니다.

실행

자동 모드 준비됨 · 마이크 권한이 필요합니다.

마이크 입력— dBFS
반전 출력 게인0%

출력은 시스템 미디어 음량 설정을 따릅니다. 브라우저에서는 실제 이어폰 음량·지연·귀에 도달하는 소음을 측정할 수 없습니다.

ANC 전후 비교

같은 환경에서 출력 OFF와 ON을 번갈아 들어보세요. 귀에서 들리는 차이를 비교하는 기능입니다.

마이크 실행 후 비교할 수 있습니다.

OFF 입력 기록—
ON 입력 기록—

표시값은 비교 버튼을 누른 뒤 3초간 기록한 마이크의 평균 dBFS입니다. 마이크 위치·자동 음량 보정·주변 소음 변화의 영향을 받으며, 귀 안의 ANC 감소량(dB)을 의미하지 않습니다. 비교 중에는 외부 소음 조건을 최대한 동일하게 유지해 주세요.

처리 방식

마이크 입력 → 저주파 대역 필터(고역·저역 차단) → 극성 반전 → 출력 제한 → 연결된 오디오 기기

주변 소음에 대한 피드포워드/피드백 ANC용 마이크 배치 및 적응형 음향 경로 보정은 제공되지 않습니다. 자동 모드는 완전한 능동 소음 제거가 아닌 반전 신호의 자동 출력 조절입니다.
