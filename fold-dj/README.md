# FOLD//MIX 2.0 — DJ mixer web test

제작 방식: HTML/CSS/JavaScript (브라우저 Web Audio API, 로컬 파일 선택). 독립 DJ UI이며 파이오니어 DJ 공식 제품 또는 로고가 아닙니다.

## 접속

https://hello-bit-code.github.io/fold-dj/

## 갤럭시 폴드 / 휴대전화 화면

- 일반 휴대전화(폭 740 CSS px 이하): `DECK A / MIXER / DECK B` 탭으로 화면을 전환하고, 하단 고정 크로스페이더를 사용합니다.
- 펼친 폴더블(폭 741px 이상) / 데스크톱: 좌우 데크와 중앙 믹서가 동시에 보입니다.
- 둘 다 개별 `음원 선택` 또는 테스트용 `DEMO` 버튼을 지원합니다.

## 조작

1. A/B에 각각 MP3/WAV 등 브라우저에서 디코딩 가능한 파일을 불러옵니다.
2. 자동 BPM 분석은 **추정값**입니다. 틀리면 각 데크의 BPM 값을 직접 입력하거나 `TAP`을 4회 이상 박자에 맞춰 누릅니다.
3. `BEAT SYNC`: 클릭한 데크의 실제 재생 BPM을 반대 데크에 맞춥니다. 두 데크가 **재생 중**이면 추정 비트그리드 기준으로 박자 위치도 보정합니다. 고정된 그리드 추정이므로 모든 곡에서 완벽한 비트매칭을 보장하지 않습니다.
4. `CUE`: 재생 중 누르면 저장된 CUE로 돌아가면서 정지합니다. 일시정지 중 위치를 이동한 다음 누르면 CUE를 설정합니다. CUE 위치에서 버튼을 길게 누르고 있으면 해당 위치부터 소리가 나오고 떼면 CUE 위치로 돌아갑니다.
5. HOT CUE: 빈 패드를 누르면 저장, 다시 누르면 재생/점프, 길게 누르면 삭제합니다.
6. 조그휠은 음원 재생 위치 이동 기능(정밀 스크래치 아님), 크로스페이더·EQ·필터·루프·믹스 녹음을 지원합니다.

## 제약

- YouTube Music 재생 중인 스트림을 다른 앱이나 브라우저에서 직접 믹싱하는 기능은 제공하지 않습니다. YouTube API 정책상 오디오 분리/변형 및 비허가 다운로드가 제한됩니다.
- 브라우저 환경의 실시간 BPM 변화는 원음 피치에도 영향을 줍니다. 키락/마스터템포는 없습니다.
- BPM 분석은 하프/더블타임, 비트 없는 인트로, 느슨한 드럼, 가변템포 곡에서 정확하지 않을 수 있습니다. 정확한 BPM을 알고 있으면 수동 값을 사용하세요.
- 일부 휴대전화 브라우저에서는 메모리 제한이나 지원 코덱 때문에 큰 파일을 열지 못할 수 있습니다.
- 음원은 서버로 업로드되지 않으며 사용자 브라우저 안에서 처리됩니다.

## 소스

- `index.html` 화면 구조
- `style.css` 폴더블/휴대전화 레이아웃 및 무광 DJ 하드웨어 스타일
- `app.js` Web Audio 2-deck mixer, controls and recording
- `bpm-engine.js` 추정 BPM 및 비트 그리드 오프셋 분석

음원 라이선스는 이용자가 관리해야 합니다.
